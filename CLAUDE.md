# Vörðu — BDD Roadmap Visualization (Tier 2 component)

Vörðu ingests Gherkin feature files and renders them as a living roadmap in the browser.
Deployed by Nidavellir as a Tier 2 platform component.

**Full agent context:** [`yggdrasil/CLAUDE.md`](../yggdrasil/CLAUDE.md) and
[`yggdrasil/docs/ecosystem-architecture.md`](../yggdrasil/docs/ecosystem-architecture.md)

```bash
python scripts/vordu_ingest.py   # or see yggdrasil/scripts/vordu_ingest.py
```
